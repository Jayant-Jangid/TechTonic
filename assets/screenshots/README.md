# Project Screenshots

Store the important screenshots and UI captures of the KisanSetu platform in this directory.

## Recommended screenshots

- `01-landing-home.png` – KisanSetu main portal with dual persona selection & role portal
- `02-farmer-dashboard.png` – Farmer crop inventory, MSP price comparison & voice assistant
- `03-consumer-marketplace.png` – Wholesale buyer discovery, crop filtering & checkout
- `04-negotiation-offers.png` – Multi-round price counter-offer bargaining interface
- `05-logistics-tracking.png` – Driver route navigation, pickup, and transit tracking
- `06-market-analytics.png` – MSP vs Mandi spreads & e-NAM seasonal trade volume charts

## Naming convention

Use standard kebab-case or numbered formats:
- `01-landing-page.png`
- `02-farmer-portal.png`
- `03-marketplace.png`
- `04-analytics.png`

Do not upload screenshots containing API keys, private tokens, or test credentials.

## Adding screenshots to README

Screenshots can be displayed in `README.md` using relative Markdown image paths:

```markdown
![KisanSetu Marketplace](assets/screenshots/03-consumer-marketplace.png)
```
